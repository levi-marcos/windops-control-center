# ⚡ WindOps API — Mentor Pack

Pacote do **Desafio Individual #3 — API NestJS**.

## Objetivo

Usar OpenCode ou Antigravity como **tutor interativo**, não como gerador automático.

## Arquivos

- `AGENTS.md` — comportamento do tutor.
- `WINDOPS_MENTOR_PROTOCOL.md` — protocolo pedagógico backend.
- `DESAFIO_03_WINDOPS_API_NESTJS.md` — desafio completo.
- `MENTORIA_STATE.md` — decisões e evidências.
- `prompts/` — prompts para iniciar, retomar, pedir ajuda, revisar e auditar.

## Como usar

1. Coloque os arquivos na raiz do workspace.
2. Abra a pasta no OpenCode/Antigravity.
3. Cole o conteúdo de `prompts/00_INICIAR_DESAFIO.md`.
4. O tutor deve ler tudo antes de codificar.
5. Responda a pergunta de nível.
6. Siga uma fase por vez.
7. Não pule validações.

## Entrega mínima

```text
NestJS
Controllers
Services
DTOs
ValidationPipe
404
regra de alerta
Swagger
testes
README
```

Persistência com Prisma/PostgreSQL é bônus após o núcleo funcional.

## Princípio

```text
IA como mentor:
explica → pergunta → recomenda → implementa junto → valida → revisa
```

e não:

```text
prompt → muitos arquivos → "pronto"
```
